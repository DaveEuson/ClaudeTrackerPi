## Yoyu v1.12.0

**Plug in a second board and the companion just finds it.** No flag, no menu
item, no knowing that either existed. Companion only; the firmware changes
nothing but the version it reports.

### Adding a board used to do nothing

The companion keeps the boards it feeds in its config, and checked that list
the sensible way: if something on it still answers, carry on. That is right
for an address gone stale and wrong for a board that has just arrived, because
one board answering tells you nothing about whether another has appeared
beside it.

So the second board sat there saying *waiting for your computer* until you
found `--rescan`, or **Look for boards** in the tray menu. Both still work.
Neither should have been necessary.

A running companion now sweeps for boards it has not seen every 15 minutes,
adopts anything new, and says which:

```
Found another board, now feeding it too: 85e050 (lcd2, v1.9.1) at http://192.168.0.76:8080
pushed [LIVE] -> 2/2 trackers: Session 34.0%, Weekly 34.0%
```

The tray does the same and tells you in a notification.

### What it will not do

**A sweep that finds nothing is ignored.** Finding no boards means the network
is unhappy at least as often as it means the boards have gone, and writing
that emptiness to the config would stop the companion feeding anything until
somebody noticed. The list is only ever changed by a sweep that found
something.

**A board that has stopped answering is dropped**, which is safe only because
this now runs on a timer: switch it back on and the next sweep picks it up
again. A board that moved to a new address is followed for the same reason,
rather than leaving a dead entry behind forever.

**A board on another subnet is kept.** The sweep only covers the ranges this
computer is on, so a board reached across a router is invisible to it. If it
still answers, it stays.

**`--pi` is left alone entirely.** Naming a board explicitly is a decision, and
going off to find others and quietly feeding them is not what was asked for.

### Turning it down, or off

`--rescan-every SECONDS` for one run, or `rescan_secs` in the config to make it
stick. `0` means never look again, and it genuinely means it.

### Upgrading

**Boards can skip this one**, as they could v1.10.0 and v1.11.0. The firmware
is unchanged apart from the version it reports.

Replace the companion. On Linux, `apt install ./yoyu-companion_amd64.deb` or
the AppImage from v1.11.0; everywhere else, download it again and run
`--install`, which upgrades in place.
